OS Visualiser 🖥️

An interactive educational tool for visualizing core Operating System concepts and algorithms. Built with HTML, CSS, and JavaScript, this project helps learners understand OS mechanisms like memory management, disk scheduling, process synchronization, and more, through intuitive and interactive visualizations.


🧩 Features

Memory Management:
Contiguous allocation (First Fit, Best Fit, Worst Fit) \
Process Synchronization 
Modular file structure: each concept has its own folder (e.g., Disk_Scheduling, Memory_Allocation, etc.)


🛠️ Technical Stack

Area :	Technologies

Frontend	: HTML5, CSS3, JavaScript (ES6+)

Visualization	: CanvasJS (for disk scheduling); pure JS + CSS for others

Styling	Custom : CSS + Bootstrap icons
