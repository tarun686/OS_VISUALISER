Disk Scheduling Algorithm Simulator

(FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK)

Disk scheduling is the process of determining the order in which disk I/O requests are serviced. These algorithms help improve efficiency and reduce seek time by determining the optimal sequence of disk accesses.

What is Disk Scheduling?

Disk scheduling is the method by which the operating system decides the order in which I/O requests will be processed by the disk controller. It plays a crucial role in minimizing seek time and improving disk performance.

Common Disk Scheduling Algorithms

There are several algorithms used to optimize the order of servicing disk requests:

  • FCFS (First-Come-First-Serve)
  • SSTF (Shortest Seek Time First)
  • SCAN
  • C-SCAN (Circular SCAN)
  • LOOK
  • C-LOOK (Circular LOOK)

FCFS (First-Come-First-Serve)

FCFS processes disk requests in the order they arrive without reordering them. It is simple but may result in long wait times if requests are far apart.

Steps:

  1. Serve requests in the order they are received.
  2. No optimization is performed.
  3. Easy to implement but inefficient for scattered requests.

SSTF (Shortest Seek Time First)

SSTF selects the disk request that is closest to the current head position, reducing seek time but possibly causing starvation.

Steps:

  1. Calculate the distance of all requests from the current head.
  2. Pick the request with the smallest distance.
  3. Repeat for the remaining requests.

SCAN (Elevator Algorithm)

The disk arm moves in one direction (like an elevator), serving all requests until it reaches the end, then reverses direction.

Steps:

  1. Move the head towards one end, serving requests in order.
  2. Once the end is reached, reverse direction.
  3. Repeat this back-and-forth motion.

C-SCAN (Circular SCAN)

Like SCAN, but instead of reversing, the head jumps back to the beginning and continues in the same direction. This provides a more uniform wait time.

Steps:

  1. Move head in one direction, serving requests.
  2. On reaching the end, jump back to the beginning.
  3. Continue serving in the same direction.

LOOK Algorithm

Similar to SCAN, but instead of going to the end of the disk, the head reverses direction when there are no more requests in that direction.

Steps:

  1. Serve requests in one direction until none remain.
  2. Reverse and continue.
  3. Avoids unnecessary movement to disk edges.

C-LOOK Algorithm

Similar to C-SCAN, but the head only jumps back to the lowest request after serving the highest one.

Steps:

  1. Serve in one direction only.
  2. Jump to the beginning request after finishing the last one.
  3. Continue in the same direction.
